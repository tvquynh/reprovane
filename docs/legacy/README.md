# Historical predecessor documentation

These files describe OpenAlex Literature Intelligence v4.1.0, before ScholarFlow
and Reprovane. Historical commands are not installed Reprovane commands. Their
machine filtering and manual PDF workflow do not define current screening or
corpus membership. Do not follow old configuration instructions for current use.

Start with the current [Quick Start](../../QUICKSTART.md) and
[User Guide](../../USER_GUIDE.md). [Provenance](../../PROVENANCE.md) records lineage.
The archived [English predecessor manual](predecessor/docs/USER_GUIDE.md) preserves
the technical background. Historical non-English entry points below now contain
English summaries; the predecessor repository and published releases are untouched.
